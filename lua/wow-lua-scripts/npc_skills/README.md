### NPC SKILLS

This script, by creating an NPC located within the `.sql` file, adds the ability for level 80 players to upgrade all learned skills to the maximum level (i.e., 400). It does not teach skills. The player must first go to the capital city to learn any skills they don't know, and then level them up with the NPC.
